# 猫毛宇宙 · 游戏教程

🖇https://vogelimkafig202.github.io/CatFurUniverse-web/

你在给一只猫梳毛。每梳成功一次，掉下来的毛就会变多，重量按指数往上跳。目标是梳到第 191 次，到达「可观测宇宙」。中途被猫抓住，并且猫条用完，这一局就结束。
登录成功后会先出现两行引导字幕。字幕还在时，鼠标点哪里都不会开始梳毛。等字幕淡出，这一局才正式开始。

## 怎么梳毛

- 按住鼠标左键，在猫身上或猫身边滑动。可梳的范围比猫本身大一圈。
- 光标在游戏画面里会变成一把梳子，尖端在左上角。
- 任意方向滑过大约 24 像素，记 1 梳。左右、上下、斜着都可以。
- 记上这一梳之后，顺着刚才的方向继续拖，不会再加次数。要转一个明显不同的方向，再滑过一段，才会记下一梳。
- 松开鼠标再按下，算一次新的动作，可以重新往任意方向梳。
- 只是碰一下、滑得太短，不会计数。

画面上方会显示梳毛次数和当前毛重。毛重只在你的屏幕上计算，排行榜只记录梳了多少次。

## 猫会回头

每一局开始时，猫的脾气是随机的。脾气决定警告隔多久出现、睁眼看多久。

- 警告时，猫会加快摇尾巴。这时还可以继续梳。
- 警告结束后，猫多半会睁眼盯着你。如果你的手还在动，就会被挠。睁眼期间再移动，也会被挠。手停住，就能安全度过。
- 也有少数警告是假动作，摇完尾巴并不睁眼。

警告的间隔不会越到后期越密，大约每两秒左右来一次，每次略有早晚。

## 猫条

开局有两根猫条，在右上角。

被挠时游戏会暂停，并询问要不要喂猫条。

- 点「确认喂猫条」：用掉一根，层数和毛重都保留，然后继续这一局。
- 两根都用完后再被挠：这一局结束，成绩会提交到排行榜。

主动玩到第 191 梳，会直接「宇宙级收工」，也会提交成绩。
## 结束之后

结算页可以：

- 再来一局：重新看引导字幕，并重新随机这只猫的脾气。
- 查看本机排行榜：看前 20 名。同一个人可以有多条记录。排序先看层数，再看有没有用过猫条，最后看时间。
- 切换账号：清除本机登录状态，回到注册或登录页。

左上角的「切换」随时可以换账号。换账号后需要重新登录。
