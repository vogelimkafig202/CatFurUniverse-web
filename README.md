# 猫毛宇宙（网页版）

这一份只包含网页。账号、猫的脾气和排行榜都记在浏览器里，不需要 Java 后端。

直接双击 `index.html` 打不开，浏览器不允许这样加载页面脚本。放到 GitHub Pages 上，或在本目录起一个本地网页服务后再打开。

## 放到 GitHub 上让别人玩

1. 在 GitHub 新建一个公开仓库。
2. 把本目录里的文件上传到仓库根目录，`index.html` 要在最外层。
3. 仓库 Settings → Pages，Source 选 `main` 分支、`/ (root)`。
4. 保存后打开 `https://你的用户名.github.io/仓库名/` 。

成绩只存在打开这个网页的那台浏览器里。换电脑、换浏览器或清除网站数据后，名字和排行榜会消失。同学之间看不到同一张榜。
